Why Aurelia 2 SSR over React Server Components (RSC)?

React Server Components mandate strict 'use client' and 'use server' boundaries, complex streaming wire formats, and heavy fiber reconciliation. Aurelia 2 operates directly against web standards and the native DOM platform—delivering clean templates, zero virtual-DOM overhead, and true two-way data binding after hydration.
