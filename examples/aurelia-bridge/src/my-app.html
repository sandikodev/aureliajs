⚖️ Architectural Discipline: Pure Polyglot Bridge vs. Islands Architecture

  • Polyglot Bridge (@aureliajs/bridge): Focuses on pure component interoperability. Enables incremental migration and shared design systems across frameworks (React, Vue, Svelte, Solid, Preact, Qwik) within a single Aurelia 2 application with live two-way reactive state.
  • Islands Architecture (@aureliajs/islands): Focuses on Zero-JS selective hydration and edge SSR performance (client:visible, client:idle, client:media). Both are strictly separated, independent bounded contexts.

4. Orthogonal Composition: <au-bridge island="...">

When combined with @aureliajs/islands, foreign runtimes (such as React 19) are neither downloaded nor mounted until triggered: 

<!-- Zero Foreign Runtime Until Element Enters Viewport -->
<au-bridge 
  island="visible" 
  using="react" 
  component.bind="HeavyChart" 
  props.bind="chartProps">
</au-bridge>

This clean monorepo architecture ensures @aureliajs/bridge handles component interop while @aureliajs/islands provides the island template controller for scheduling lazy partial hydration.
