Enterprise Pedigree: Dari mana datangnya arsitektur ini?

Diciptakan oleh Rob Eisenberg (yang sempat menjadi arsitek awal Angular 2 sebelum keluar karena friksi desain dengan Google), Aurelia membawa filosofi Convention over Configuration, Class-based ViewModels murni, dan IoC Container tingkat tinggi yang sangat familiar bagi insinyur backend Spring Boot, ASP.NET Core, dan NestJS.

2. Universal Polyglot Bridge: Orkestrasi 6 Framework Frontend di Aurelia

Aurelia 2 dapat menampung dan mengorkestrasi komponen library manapun secara native di dalam pohon komponen Aurelia. Melalui elemen deklaratif <au-bridge using="...">, semua framework di-mount secara otomatis dengan reactive two-way binding tanpa boilerplate wrapper manual!

Nilai Shared State di Aurelia ViewModel: ${sharedCounter}

State di atas dibagikan via value.bind="sharedCounter" ke 6 framework berbeda di bawah ini. Setiap tombol di dalam React, Vue, Svelte, Solid, Preact, atau Qwik akan memperbarui ViewModel Aurelia secara dua arah dan sinkron!

⚖️ Disiplin Arsitektural: Pure Polyglot Bridge vs Islands Architecture

  • Polyglot Bridge (@aureliajs/bridge): Berfokus pada interoperabilitas komponen murni. Memungkinkan migrasi bertahap dan penggunaan design system lintas framework (React, Vue, Svelte, Solid, Preact, Qwik) di dalam satu aplikasi Aurelia 2 dengan live two-way reactive state.
  • Islands Architecture (@aureliajs/islands): Berfokus pada Zero-JS selective hydration dan performa edge SSR (client:visible, client:idle, client:media). Keduanya adalah bounded context independen yang terpisah secara tegas!

4. Komposisi Ortogonal: <au-bridge island="...">

Saat dikombinasikan dengan @aureliajs/islands, runtime foreign (seperti React 19) tidak akan diunduh maupun di-mount sebelum pemicu (trigger) aktif: 

<!-- Zero Foreign Runtime Sampai Elemen Terlihat di Viewport -->
<au-bridge 
  island="visible" 
  using="react" 
  component.bind="HeavyChart" 
  props.bind="chartProps">
</au-bridge>

Fitur ini membuktikan arsitektur monorepo yang bersih: @aureliajs/bridge fokus pada interop komponen, sementara @aureliajs/islands menyediakan template controller island untuk scheduling lazy partial hydration.

5. Matriks Perbandingan Arsitektur: Enterprise vs Mainstream

Aspek AngularJS / AureliaJS React-like (React, Solid, Qwik) Vue / Svelte
Paradigma Utama Enterprise OOP, MVVM, IoC Container, Dependency Injection Functional UI Runtime, JSX, Immutability, Unidirectional Data HTML-First, Single-File Components, Progressive Enhancement
Analogi Backend Java Spring, C# .NET, NestJS (Class + Decorator + DI) Pure Functions, Pipelines, State Machines Express / Standard Web (Pragmatis, Minim Seremoni)
Komparasi Apple-to-Apple Sebanding antara sesama Enterprise Framework (Angular & Aurelia) Solid, Preact, Qwik (React-like family) Vue paling sebanding dengan Svelte (Native HTML feeling)
Polyglot Interoperability Aurelia mengorkestrasi React/Vue/Svelte via <au-bridge> Biasanya menjadi library yang di-mount, bukan container utama Memerlukan wrapper custom jika di-host di luar ekosistemnya
