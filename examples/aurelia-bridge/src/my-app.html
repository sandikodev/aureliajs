4. Universal Bridge Protocol: <au-bridge using="...">

A single declarative contract orchestrates any frontend framework inside Aurelia 2 without glue code: 

<!-- Pure Universal Declarative Bridge Syntax -->
<au-bridge 
  using="react | vue | svelte | solid | preact | qwik" 
  component.bind="WidgetComponent" 
  props.bind="{ value: sharedCounter, onChange: handleUpdate }">
</au-bridge>

The IBridgeRegistry manages framework adapters as pluggable services, handling mounting, reactivity propagation, and DOM cleanup automatically across all component lifecycles.
