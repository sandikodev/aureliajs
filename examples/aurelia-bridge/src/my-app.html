Architectural Boundary: Enterprise Host vs. Specialized Leaf Widgets

Aurelia 2 (Enterprise Host) owns the application backbone: IoC container, domain services, audit trails, and host-level DOM coordination. Foreign Frameworks (Leaf Components) own their isolated internal states and native DOM manipulation (React refs, Vue template refs, Svelte bindings, Solid signals) while seamlessly synchronizing shared metrics via <au-bridge>.

4. Orthogonal Composition: <au-bridge island="...">

When combined with @aureliajs/islands, foreign runtimes (such as React 19) are neither downloaded nor mounted until triggered: 

<!-- Zero Foreign Runtime Until Element Enters Viewport -->
<au-bridge 
  island="visible" 
  using="react" 
  component.bind="HeavyChart" 
  props.bind="chartProps">
</au-bridge>

This clean monorepo architecture ensures @aureliajs/bridge handles component interop while @aureliajs/islands provides the island template controller for scheduling lazy partial hydration.
